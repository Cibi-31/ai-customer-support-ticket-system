# AI-Powered Customer Support Ticket Classification System

## Overview

This project classifies customer support tickets using Machine Learning and NLP. It also performs sentiment analysis, priority prediction, and generates AI-powered responses using Groq Llama 3.

## Features

* Ticket Classification
* Sentiment Analysis
* Priority Prediction
* Groq AI Response Generation
* CSV Dataset Upload
* Streamlit Dashboard

## Technologies Used

* Python
* Streamlit
* Scikit-Learn
* TF-IDF
* Random Forest
* TextBlob
* Groq API
